# Eisenhower Matrices

An Eisenhower Matrix web application to keep track of tasks, prioritize by urgency & importance, and collaborate in real-time.

## Subproject Configuration

- **Subproject Slug**: `eisenhower-matrices`
- **Firebase Project**: `portfolio-800ba`
- **Firestore Collections Prefix**: `eisenhower-matrices_`
  - `eisenhower-matrices_matrices`
  - `eisenhower-matrices_users`

---

## Features

- **Guest Mode**: Tasks and matrix configurations saved locally in browser `localStorage`.
- **Firebase Auth**: Sign in with Email/Password or Google OAuth.
- **Multiple Matrices**: Create new Eisenhower Matrices and switch seamlessly between them.
- **Real-Time Collaboration**: Share matrices with teammates by email address for simultaneous collaboration and task tracking.
- **Header & Footer**: Standardized portfolio header navigation and "A Jordan Katz Project" footer.
